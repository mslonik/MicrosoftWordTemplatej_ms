Default locations of fonts in Microsoft Windows Operating System:
1. C:\Windows\Fonts
User specific fonts:
2. %LOCALAPPDATA%\Microsoft\Windows\Fonts

Quick way to access the Fonts folder:
Run command: shell:fonts
